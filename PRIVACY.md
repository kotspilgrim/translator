# Политика конфиденциальности — RU ⇄ KO Переводчик

_Последнее обновление: [дата публикации]_

Это черновик, подготовленный для формы Data Safety в Google Play Console.
Перед публикацией: (1) разместить текст на публичном URL (например, GitHub
Pages из этого репозитория), (2) вписать этот URL в Play Console и в
`frontend/app.json` при необходимости, (3) проверить и при желании
скорректировать формулировки — это черновик, а не юридическая консультация.

## Какие данные собираются

**При регистрации через email/пароль:**
- Email — для входа и связи с аккаунтом.
- Пароль — хранится только в виде хэша (bcrypt), в открытом виде нигде не
  сохраняется.
- Имя (опционально) — если указано при регистрации.

**Гостевой режим** (кнопка «Продолжить как гость») не требует регистрации и не
собирает email/пароль вообще — переводы в этом режиме работают без аккаунта.

**Голос и текст для перевода:**
- Голос, произнесённый в приложение, распознаётся в текст через системный
  сервис распознавания речи Android (Google) — приложение само это аудио не
  сохраняет и не передаёт на свой сервер.
- Текст, который нужно перевести, отправляется:
  - на сервер приложения → в OpenAI (GPT-4o) — при переводе онлайн;
  - **или** обрабатывается полностью на устройстве через Google ML Kit — при
    офлайн-переводе (в этом случае текст никуда не передаётся с телефона).
- Переводы могут журналироваться на сервере (таблица `translations` в
  Supabase) для истории и разработки функций — вместе с выбранным сценарием и,
  если пользователь авторизован, с его аккаунтом. Хранятся до тех пор, пока
  пользователь не запросит удаление (см. «Права пользователя» ниже).

**История переводов на устройстве:** хранится локально (AsyncStorage) и
автоматически удаляется через 24 часа. Приложение не отправляет эту локальную
историю на сервер.

## Для чего используются данные

- Email/пароль — авторизация и восстановление доступа к аккаунту.
- Голос/текст — единственная цель: перевод между языками, основная функция
  приложения.
- Данные не используются для рекламы, профилирования или продажи третьим
  лицам.

## Кому передаются данные

| Сервис | Что получает | Зачем |
|---|---|---|
| OpenAI (GPT-4o) | Текст для перевода (без email/имени) | Онлайн-перевод |
| Google ML Kit | Текст для перевода — обрабатывается локально на устройстве | Офлайн-перевод |
| Supabase | Email, хэш пароля, история переводов | Хранение аккаунта и истории |
| Resend | Email | Отправка кода подтверждения при регистрации |
| Google (Android STT) | Аудио с микрофона | Распознавание речи в текст |

Ни один из этих сервисов не получает данные для собственных маркетинговых
целей — только для выполнения конкретной функции приложения.

## Права пользователя

- Удаление аккаунта и связанных данных — по запросу на [email для связи].
- Отзыв доступа к микрофону — в настройках Android в любой момент; без него
  недоступен только голосовой ввод, текстовый перевод продолжает работать.

## Дети

Приложение не предназначено для детей младше 13 лет и не собирает данные
целенаправленно от этой аудитории.

## Изменения в этой политике

Актуальная версия всегда доступна по этому же адресу. При существенных
изменениях дата в начале документа будет обновлена.
